# TheFrontier

First-person sci-fi shooter and base defense. You hold a planetary basin around a living **core**. Mobs come in rest/wave cycles. During both phases you gather scrap and crystal, build walls, turrets, traps, and utility, and fight on foot.

This repository is a playable Godot 4.7 vertical slice. Meshes are greybox primitives named so Blender `.glb` assets can replace them later.

## Requirements

- [Godot 4.7.2](https://godotengine.org/download/archive/4.7.2-stable/) (Forward Plus)
- No paid assets or online services

## Run

1. Open this folder in Godot 4.7.2 (`Project → Import`).
2. Press **F5**. The main menu is the run scene.
3. Pick a mode.

Headless checks:

```bash
godot --headless --path . --import --quit
godot --headless --path . --script res://tests/run_tests.gd
```

Or `bash scripts/ci/run_tests.sh` if `godot` is on your `PATH`.

## Game modes

Modes are resources in `data/modes/`. The main menu lists whatever is there.

1. **Survive** — win after 3 waves. Lose if the core dies.
2. **Gather** — recover 4 of 6 signal relics. Waves still run.
3. **Escape** — gather enough scrap/crystal and place the **Escape Ship**.
4. **Endless** — no win. Waves after 3 are generated by `WaveScaler`. Score is kills, waves, and relics.

Player death: you drop 15% of carried scrap and respawn at the core after 5 seconds if the core is still alive. Core destruction is always a loss.

## Placeholders

All art is self-made CSG-style primitives. Swap later by replacing the `Visual` child on a prefab (`asset_slot` metadata). See `assets/placeholders/README.md` and `docs/AGENT_CONTEXT.md`.

No third-party audio, textures, or models are included. Engine: Godot 4.7.2 (MIT).

## Tests and CI

`tests/run_tests.gd` covers economy, building costs, placement, wave scaling, win/lose, session rest→wave, death tax, and escape victory. GitHub Actions (`.github/workflows/ci.yml`) downloads Godot 4.7.2 and runs the same suite plus a 2-second headless boot of the main menu.
